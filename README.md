# ☕ Java 스터디 그룹

## 📋 스터디 개요
- **참여 인원**: 6명
- **진행 기간**: 8주
- **목표**: Java 기초 문법 완전 정복

## 📚 커리큘럼

### 1주차 - Java 시작하기
- 개발 환경 설치 (JDK, IntelliJ IDEA)
- Hello Java 프로그램 작성
- Java 기본 문법과 표기법 이해

### 2주차 - 변수의 이해
- 변수 개념 및 데이터 타입 학습
- 변수를 활용한 간단한 프로그램 제작

### 3주차 - 연산자 활용
- 산술, 비교, 논리 연산자 학습
- 연산자를 활용한 프로그램 제작

### 4주차 - 변수 & 연산자 실습
- 변수와 연산자 종합 활용
- 개념 훈련 및 실습 문제 해결

### 5주차 - 조건문 마스터
- if, else if, else, switch 문 학습
- 조건문을 활용한 프로그램 제작

### 6주차 - 반복문과 배열
- for, while, do-while 문 학습
- 1차원 배열 개념 및 활용
- 반복문과 배열을 조합한 프로그램 제작

### 7주차 - 종합 실습
- 조건문과 반복문 통합 활용
- 복합적인 로직 구현 연습
- 개념 정리 및 심화 문제 해결

### 8주차 - 최종 평가
- 학습 내용 종합 테스트
- 프로젝트 발표 및 코드 리뷰

## 🎯 학습 목표
- Java 기본 문법 완전 이해
- 변수, 연산자, 조건문, 반복문 자유자재로 활용
- 간단한 프로그램을 스스로 설계하고 구현할 수 있는 능력 배양
